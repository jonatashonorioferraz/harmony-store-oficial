Como funciona este teste

O número do pedido deve coincidir na etiqueta e no checklist. O texto é reorganizado a partir da imagem original, sem OCR. Títulos idênticos consecutivos aparecem uma vez; cada variação e quantidade permanece separada.

Quantidade é a coluna Qnt do checklist, sem multiplicar as peças do kit. Quando não há variação, siga a descrição. Para personalizados, confira os detalhes no pedido.

Se o modelo não for reconhecido, houver duplicidade ou a lista não couber, use o conversor normal. Este beta aceita apenas o modelo Shopee testado; não processa Mercado Livre nem substitui o conversor atual. Ao sair desta aba, o teste é descartado.
